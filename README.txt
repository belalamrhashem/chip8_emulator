This project was me developing a CHIP8 emulator alongside my university coursework to learn about low-level programming. I was able to create an emulator with a basic GUI that runs a suite of games provided by the user and also allows for basic settings to be changed (I allowed gameplay speed to be changeable, similar principles could be applied to display resolution, sound volume, etc.)
